Mes storyboards

Raccourcis et gestes
  • Glisser le fond : se déplacer · Molette / pincer : zoomer
  • Maj + glisser : sélectionner plusieurs éléments
  • Point ● : glisser pour relier, cliquer pour créer la suite
  • Double-clic : écrire dans un élément · sur le fond : ajouter
  • Ctrl+V : coller un lien vidéo, une image ou du texte
  • Ctrl+Z / Ctrl+Y : annuler / rétablir · Ctrl+D : dupliquer
  • Ctrl+B / I / U : gras, italique, souligné pendant l'écriture
  • Ctrl+F : rechercher · Entrée : écrire dans l'élément sélectionné
  • Suppr : effacer · F : tout voir · Espace + glisser : se déplacer

Vos storyboards restent dans ce navigateur. Sauvegardez-les en .json pour les garder ailleurs.

Ajouter une vidéo par lien

TikTok, Instagram (reels et posts), Facebook, YouTube, Vimeo, Google Drive, ou l'adresse directe d'une image ou d'une vidéo.

Partager l'aperçu

Lien de consultation

La personne ouvre le lien et voit le storyboard en lecture seule : vidéos, fils, présentation et vue liste. Rien à installer.

WhatsApp E-mail Voir l'aperçu

Fichier d'aperçu

Un seul fichier .html qui contient tout, même les images et vidéos importées depuis l'appareil. À envoyer par e-mail, WhatsApp ou WeTransfer : il s'ouvre dans n'importe quel navigateur.

Projet modifiable

Pour qu'une autre personne modifie le storyboard : elle l'ouvre avec « Mes storyboards › Ouvrir un fichier ».
